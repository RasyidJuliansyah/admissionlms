# plugins/ (opsional)

Folder ini untuk mengembangkan plugin sendiri sebelum dipublikasikan ke marketplace.
Claude Code memasang plugin lewat perintah `/plugin` dari marketplace, bukan otomatis dari folder ini.
Manifest plugin umumnya berada di `<nama-plugin>/.claude-plugin/plugin.json`. Cek dokumentasi resmi
Claude Code untuk format terbaru karena bagian ini cukup sering berubah.
